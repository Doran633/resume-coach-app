# v0.0 Plan

v0.0 is an internal development baseline. It is not the campus-wall launch version.

Core loop:

```text
experience input -> mock generation -> three packaging versions -> claim risk -> interview plan -> DOCX -> feedback -> event logs
```

Non-goals:

- login
- payment
- PDF
- resume upload
- multi-turn chat
- admin dashboard
- real LLM integration

Success criteria:

- API can generate structured result.
- Frontend can show result.
- DOCX can be generated and downloaded.
- Events and feedback are stored in SQLite.
